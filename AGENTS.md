## Fluxo Git ao Finalizar Tarefas
- Sempre que concluir uma tarefa que envolva alterações no repositório (após validar build/testes aplicáveis), faça o commit das mudanças e execute `git push` para enviar ao GitHub (`origin`), a menos que o usuário peça explicitamente para não enviar ou haja falhas impeditivas.
- Antes de concluir a resposta final, confirme se não ficaram commits locais pendentes de push.
